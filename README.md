- Objective: The project solves 1-D Source free, convection-diffusion general problem.
- Methodology: FINITE VOLUME METHOD (FVM) is used with central differencing for spatial discretization.
- Implementation: Standalone python code is provided. The code is self-contained and includes everything required for execution, with no separate parameter files or solver files needed.
- Results: 2 plots and tables are provided , for péclet number of 1 and 5 respectively, From this investigation we can say that Central difference scheme in Finite
  Volume Method produces accurate results for −2 ≤ P e ≤ 2.
